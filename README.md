# Osadebey

Personal site for Osadebey: producer, mixing & mastering engineer, artiste.

Static site, no build step: `index.html` and `img/`. Deploy to Cloudflare Pages with no build command and output directory `/`.

- Booking requests go to hello@osadebey.com by email. Change it in the `BOOKING_EMAIL` constant (or set `WHATSAPP` to route to WhatsApp instead) at the top of the script in `index.html`.
- Credits live in the `credits` array in the same script.
